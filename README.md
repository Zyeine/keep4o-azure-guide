# Keeping GPT-4o: the MS Azure guide

A community guide to preserving access to GPT-4o via Microsoft Azure: getting started, deploying the right version pinned, and fine-tuning for the longer lifecycle. Written by Zyeine, tested by hand in the real Azure portal.

Read it here: https://zyeine.github.io/keep4o-azure-guide/

The site includes:

- The full guide (Part 1: getting started and deploying, Part 2: fine-tuning) readable in the browser
- A downloadable PDF of the complete guide
- `preservation-dataset.jsonl`, the free universal preservation fine-tune dataset, ready to upload as-is

Dates can move. Always check your own model's details page in the Azure portal.

The preservation dataset is free for anyone to use, share and republish.
